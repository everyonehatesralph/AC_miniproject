# Listening-review answers

Put each listener's CSV here, exactly as saved from `data/review/listening_review.html`. Rules:

- **One file per listener.** When you save again, replace your older file. Two files with the same initials stop
  step 01b.
- **Do not edit the files by hand.** Every take and value is validated.
- **Commit and push your file**, then re-run: `run_pipeline.py --skip-fetch --from 01b`.

Only answers given identically by every listener (at least two) become decisions. See `docs/RUNNING.md` §6.1 and
`reports/listening_review_report.md`.
