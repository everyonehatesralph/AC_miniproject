- **FINAL**: settled by the protocol or by evidence.
- **PENDING-GROUP**: needs Group 3's confirmation.
- **PENDING-INSTRUCTOR**: needs a ruling on the protocol.

Each decision is implemented in code (file given). It can be changed by editing that code or the named override
file, followed by a re-run.
